# Showcase Programming

A small collection of Luau/Lune modules and examples.

This repository is primarily intended as a template for how I structure smaller modules and projects. It demonstrates a simple organization style with type definitions, examples, documentation, and reusable code.

## Contents

* Modular Luau code
* Strict type definitions
* Usage examples
* Documentation examples
* Utility modules

# Purpose

The goal of this repository is to provide concise, easy-to-read examples of module design and project structure in Luau and Lune.

Nothing here is intended to be a complete framework or production-ready package. Instead, this repository serves as a reference, showcase, and starting point for future projects.
